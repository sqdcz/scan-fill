# ScanFill 扫描填入 - 使用说明

> 复刻 iOS「摄像头扫描输入」的安卓原生应用：拍照/相册取图 → 本地 OCR 识别 → 自动填入任意 App 的输入框。

- 版本：v1.0.0（versionCode 1）

- 交付物：`D:\admin\文档\ScanFill-v1.0-release.apk`（约 54 MB，已用调试密钥签名）

- 最低支持：Android 7.0（API 24）｜ 目标：Android 16（API 36）

- 支持架构：arm64-v8a、armeabi-v7a

***

## 一、安装

1. 把 `ScanFill-v1.0-release.apk` 传到手机（微信/QQ/USB 均可）。
2. 点击 APK 安装，系统会提示「未知来源应用」，允许即可。
3. 首次打开 App 会依次申请：**相机**、**通知**、**相册（媒体访问）** 权限，全部允许。

### 必须手动开启的两个系统开关

| 开关    | 路径                               | 作用              |
| ----- | -------------------------------- | --------------- |
| 悬浮窗权限 | 系统设置 → 应用 → ScanFill → 显示在其他应用上层 | 悬浮球能在任何界面弹出     |
| 无障碍服务 | 系统设置 → 无障碍 → 下载的服务 → ScanFill 填入 | 实现「全选 + 粘贴」自动填入 |

App 内 MainActivity 首页也放了这两个开关的直达按钮，点一下就跳转到对应设置页。

***

## 二、四种启动扫描的方式

| 方式         | 操作                         | 适用场景                   |
| ---------- | -------------------------- | ---------------------- |
| **悬浮球**    | 点桌面球 → 弹扫描页                | 任何 App 内随时调用（最常用）      |
| **长按编辑菜单** | 任意输入框长按 → 菜单选「扫描填入」        | 想替换当前选中文字时用，识别结果直接替换选区 |
| **快捷磁贴**   | 下拉状态栏 → 编辑磁贴 → 添加 ScanFill | 不想开悬浮球时的备选入口           |
| **应用内**    | 打开 App → 扫描按钮              | 单纯想取文字，不填入别的 App       |

悬浮球可拖动，松手自动贴边；长按可隐藏。

***

## 三、扫描页操作

- **快门**：拍照识别。

- **相册按钮**：从相册选图识别。

- **最近照片露角**：相册按钮上方会露出相册最新一张的缩略图，直接点它就是「用刚拍的那张」，不用进相册。

- **闪光灯**：暗光环境补光。

- **识别完成后**：结果卡片中可二次编辑文字，然后：

  - **填入**：走「无障碍全选+粘贴」直接写进当前输入框；未开无障碍时自动降级为「复制到剪贴板」，手动粘贴即可。

  - **复制**：只复制不填入。

***

## 四、OCR 引擎（双引擎，纯离线）

| 引擎        | 特点                   | 说明                |
| --------- | -------------------- | ----------------- |
| ML Kit 中文 | Google，速度快           | 首次使用自动下载模型，之后完全离线 |
| PaddleOCR | 百度 PP-OCRv4，生僻字/竖排更强 | 模型打包在 APK 内       |

设置 → OCR 里随时切换。切换后立即生效，无需重启。

## 五、设置项一览（分级结构）

- **主题**

  - 模式：亮色 / 暗色 / 跟随系统 / 定时切换（自选起止时间）

  - 玻璃风格：高斯模糊 / 液态玻璃（Android 12+ 真实模糊，低版本自动降级为半透明）

- **OCR**：引擎切换、识别语言

- **文本格式化**

  - 换行处理：保留 / 合并 / 智能合并

  - 中英文之间补空格：开 / 关

  - 段落间空行：保留 / 压缩

- **悬浮球**：大小、透明度、颜色（纯白/纯黑）

## 六、开发与构建

### 环境

- 纯原生：Kotlin + AGP 9.0.1 + Gradle 9.1.0

- JDK：Zulu 21（`C:\Program Files\Zulu\zulu-21`）

- Android SDK：`D:\android-sdk`

### 常用命令（在 `D:\admin\文档\ScanFill` 目录下）

```powershell
# Gradle Wrapper 已配置腾讯镜像，首次会自动下载 Gradle 9.1.0
.\gradlew.bat assembleRelease     # 构建 Release APK
.\gradlew.bat assembleDebug       # 构建 Debug APK
.\gradlew.bat installRelease      # 构建并直接装到已连接的手机
.\gradlew.bat --version           # 检查环境
```

构建产物位于 `app\build\outputs\apk\release\app-release.apk`。

> 当前 Release 使用调试密钥签名，方便自装自用；以后要上架或正式分发时再换正式 keystore。

### 桌面快捷方式（可选）

在桌面新建快捷方式，目标填：

```
powershell.exe -NoExit -Command "cd 'D:\admin\文档\ScanFill'; .\gradlew.bat installRelease"
```

双击即「构建 + 装机」一条龙。也可以直接为 `D:\admin\文档\ScanFill` 文件夹建快捷方式。

## 七、常见问题

| 问题            | 处理                                       |
| ------------- | ---------------------------------------- |
| 悬浮球不出现        | 检查「显示在其他应用上层」权限；被系统省电策略杀掉时重新打开一次 App     |
| 点「填入」没反应      | 无障碍服务被系统关闭了（部分机型重启后会关），重新开启；或直接用「复制」手动粘贴 |
| 长按菜单里没有「扫描填入」 | 该 App 的输入框不支持系统文本处理菜单（如部分自绘输入框），改用悬浮球入口  |
| ML Kit 首次识别慢  | 首次需下载模型，之后离线秒开；介意体积可切 PaddleOCR          |
| 识别结果格式乱       | 设置 → 文本格式化里调整换行/空格策略                     |
